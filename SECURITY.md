# Security policy

## This repository is not a secure messenger

There are no supported releases. The default branch is experimental and unaudited. Do not use it for
real or sensitive communication.

## Report privately

Do **not** disclose suspected vulnerabilities in public issues, discussions, pull requests, social
media, or chat rooms.

When this repository is published on GitHub, use the repository's **Security** tab and select
**Report a vulnerability** to open a private security advisory. Public publication is blocked until
GitHub private vulnerability reporting is enabled and verified.

Include:

- affected commit and platform;
- attacker prerequisites;
- minimal reproduction steps;
- security impact and affected invariant;
- logs or artifacts with all real user data and secrets removed; and
- whether you plan to publish and any proposed disclosure date.

We aim to acknowledge a private report within seven calendar days and provide best-effort updates.
This is not a fix SLA. There is currently no bug bounty and no promise of payment.

## Scope

In scope: code and documentation on the current default branch. Dependencies may be reported when the
issue is specifically exposed by this integration.

Out of scope: social engineering, denial of service against third parties, access to data that is not
yours, destructive testing, third-party infrastructure, and claims that merely restate documented
Phase 0 limitations.

Do not access another person's data, degrade a service, retain sensitive data, or publish before a
coordinated fix/disclosure decision. Any future safe-harbor language requires counsel review; none is
promised by this experimental policy.
